DATA-CACHE ASSOCIATIVITY COMPARISON
==================================

Benchmark: inputs/cache/associativity.x
Fixed parameters: 64 KiB data cache, 32-byte blocks
Changed parameter: DATA_CACHE_ASSOCIATIVITY
Baseline simulator: 53,258 cycles, IPC 0.692

Associativity   Baseline cycles   Simulator cycles   Baseline IPC   Simulator IPC   Register comparison
1 way           53,258            462,958            0.692          0.080           OK
2 ways          53,258            462,958            0.692          0.080           OK
4 ways          53,258            462,958            0.692          0.080           OK
8 ways          53,258             53,758            0.692          0.686           OK

All configurations retired 36,872 instructions with identical architectural
register contents. The benchmark repeatedly accesses eight blocks mapped to
one set. Configurations with fewer than eight ways thrash; all eight blocks fit
when the cache has eight ways.

Commands used (replace VALUE with 1, 2, 4, or 8):
  gcc -g -O2 -DDATA_CACHE_ASSOCIATIVITY=VALUE src/*.c -o sim
  python3 run.py inputs/cache/associativity.x
